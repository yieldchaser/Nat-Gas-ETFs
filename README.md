# Blue Meridian

Blue Meridian is a client-side analytics terminal and market data visualization platform for commodity derivatives and exchange-traded products.

## Overview

The platform aggregates public market telemetry to deliver interactive time-series charting, statistical distribution models, and multi-timeframe volume profiling across natural gas instrument series.

## Functional Modules

- **Volume Profiling**: Multi-timeframe distribution views and historical anomaly indicators.
- **Capital Flows**: Daily unit dynamics and normalized rolling volume aggregates.
- **Cycle Analytics**: Historical range oscillations and peak-to-trough interval modeling.
- **Volatility Metrics**: Integration with historical variance surfaces and implied volatility indices.

## Technical Architecture

- **Frontend**: Vanilla JavaScript (ES6+), HTML5 Canvas, modern CSS grid layout
- **Pipeline**: Automated data fetch and normalization workflows
- **Deployment**: Static delivery with zero external runtime dependencies
